Redline settings

Each pair compares pages on one site with the same path on another. Turn it on in a tab with the toolbar button or Alt+Shift+R, or add ?redline to the address.

How it reads a page

Redline fetches the reference page with your cookies for that site and reads both pages as text blocks: paragraphs, headings, list items, table cells and so on. Blocks the reference has the same are left alone. New words are highlighted and removed words struck through beside them; B switches between all changes, only what was added, and only what was removed; J and K go to the next and previous change.

It compares the two pages as their servers send them, before any script runs, and uses the live page only to find each block on screen. So text a script draws in the browser, like a clock or a relative date, never counts as a change. A page built entirely in the browser has no server text, so there Redline diffs the live page against the reference's server text instead.

Use "Ignore" for text that differs between the servers but is not content: footnote numbers that shift when a note is added, a build time, a version string.
